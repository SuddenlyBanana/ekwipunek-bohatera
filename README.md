# Tekstowy ekwipunek bohatera

Program konsolowy w Pythonie przedstawiający ekwipunek bohatera i sklep.

## Funkcje

- wyświetlanie przedmiotów, ich liczby i łącznej wagi,
- kupowanie przedmiotów za złoto,
- blokada zakupu przy braku złota lub przekroczeniu limitu wagi,
- sprzedawanie przedmiotów za połowę ceny sklepowej,
- używanie przedmiotów i usuwanie wpisu po zużyciu ostatniej sztuki,
- sprawdzanie opisu, wagi, ceny i posiadanej liczby przedmiotu,
- menu działające w pętli aż do wybrania opcji wyjścia.

## Uruchomienie

Wymagany jest Python 3.10 lub nowszy.

```bash
python3 main.py
```

## Testy

```bash
python3 -m unittest -v
```

Projekt nie wymaga instalowania żadnych dodatkowych bibliotek.
